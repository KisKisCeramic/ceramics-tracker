# 🔗 Интеграция с Google Sheets — пошаговая инструкция

## Что нужно сделать (5 минут)

### Шаг 1. Откройте таблицу
https://docs.google.com/spreadsheets/d/1dh3vJuq2skWs0PnXk941Pyfz_8gFldAc1qU8MWW9AXc/edit

### Шаг 2. Откройте Apps Script
В меню таблицы: **«Расширения» → «Apps Script»**

Откроется редактор кода в новой вкладке.

### Шаг 3. Вставьте код
1. Удалите весь код по умолчанию (выделите всё → Delete)
2. Откройте файл `apps-script.js` на компьютере
3. Скопируйте весь код
4. Вставьте в редактор Apps Script
5. Нажмите **Сохранить** (Ctrl+S) → назовите проект «КераМика»

### Шаг 4. Разверните как веб-приложение
1. Нажмите кнопку **«Развернуть»** (правый верхний угол)
2. Выберите **«Создать развёртывание»** → **«Веб-приложение»**
3. Настройте:
   - **Тип доступа**: «Все, у кого есть ссылка» (или «Все»)
   - **Кто получает доступ**: «Я» (или «Любой»)
4. Нажмите **«Развернуть»**
5. Google попросит подтвердить доступ — нажмите **«Разрешить»**
6. Скопируйте URL вида:
   ```
   https://script.google.com/macros/s/AKfycb.../exec
   ```

### Шаг 5. Подключите в приложении
1. Откройте `ceramics-tracker.html` в браузере
2. Вкладка **«Ещё»** → раздел **«Google Sheets»**
3. Вставьте URL в поле **«URL Apps Script»**
4. Нажмите **«Подключить»**
5. Нажмите **«Синхронизировать товары»** — запишет все 15 товаров в таблицу

## Как это работает

```
📱 Сканирование QR
    ↓
🌐 POST запрос на Google Apps Script
    ↓
📊 Google Sheets обновляется
    • Лист «Продажи»: +1 строка
    • Лист «Товары»: −1 остаток
```

## Меню в таблице

После установки скрипта в таблице появится меню **«🏺 КераМика»**:
- **Сбросить остатки** — обнулить все остатки
- **Статистика за сегодня** — продано шт и выручка за сегодня

## Проверка работы

1. Откройте таблицу
2. В приложении отсканируйте любой товар
3. Нажмите «Продано»
4. Обновите таблицу — новая строка в «Продажи», остаток уменьшился

## Если что-то не работает

| Проблема | Решение |
|----------|---------|
| «Ошибка доступа» | В развёртывании выберите «Все, у кого есть ссылка» |
| «Товар не найден» | Нажмите «Синхронизировать товары» в приложении |
| «Не удаётся отправить» | Проверьте интернет на телефоне |
| Данные не появляются | Обновите страницу таблицы (F5) |
